# VGV FFCA Plugin

A [Claude Code](https://claude.com/claude-code) plugin that operationalizes [Feature-First Clean Architecture (FFCA)](https://engineering.verygood.ventures/architecture/ffca/overview/) for Flutter monorepos.

The plugin lives in [`plugin/`](plugin/). Its [README](plugin/README.md) covers installation, skills, the agent, hooks and MCP tools.

## Repository layout

| Path                                 | What it holds                                                           |
| ------------------------------------ | ----------------------------------------------------------------------- |
| [`plugin/`](plugin/)                 | Everything the plugin loads. This is the folder users install.          |
| [`scripts/`](scripts/)               | Validator tests, their fixtures, and the reference sync. Not installed. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to add or change a skill, and how to test it locally.               |
